# Figma Prototype

## Azure Campus VPN – Site-to-Site Secure Connection

This interactive prototype demonstrates the proposed solution for
secure connectivity between a campus network and an Azure Virtual
Network using Azure VPN Gateway and a Site-to-Site IPsec/IKE VPN.

## Prototype Screens

1. Dashboard Overview
2. Network Architecture
3. VPN Configuration
4. Connection Test
5. IKE Proposal Mismatch
6. Asymmetric Routing

## Prototype Flow

Campus Network
→ Campus Router
→ IPsec/IKE VPN Tunnel
→ Azure VPN Gateway
→ Azure VNet
→ Azure Resources
